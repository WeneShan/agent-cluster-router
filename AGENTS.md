# Agent Skills Configuration

## Issue tracker

Issues are tracked in GitHub Issues for `WeneShan/agent-cluster-router`. Use `gh issue` CLI for all issue operations.
See `docs/agents/issue-tracker.md`.

## Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.
See `docs/agents/triage-labels.md`.

## Domain docs

Single-context layout: `CONTEXT.md` at repo root, ADRs in `docs/adr/`.
See `docs/agents/domain.md`.
