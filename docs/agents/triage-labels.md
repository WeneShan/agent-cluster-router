# Triage Labels

The `triage` skill moves issues through a state machine using these five labels:

| Role | Label | Meaning |
|------|-------|---------|
| Evaluate | `needs-triage` | Maintainer needs to evaluate |
| Info gather | `needs-info` | Waiting on reporter |
| Agent-ready | `ready-for-agent` | Fully specified, agent can pick up |
| Human-needed | `ready-for-human` | Needs human implementation |
| Closed | `wontfix` | Will not be actioned |

All labels use their canonical names. No overrides configured.
